# Reporting a vulnerability

If you find a vulnerability in macflow-check itself (for example, a way to make it run a program, change a file, or print a secret it found), please report it privately:

1. Go to the repository's **Security** tab and choose **Report a vulnerability** (GitHub private vulnerability reporting).
2. Describe what you found, how to reproduce it, and the version (`macflow-check --version`).

Please do not open a public issue for a vulnerability. You should get a reply within 7 days. Once a fix is released, the advisory will be published with credit to you unless you prefer otherwise.

A check that misses a risky setting, or reports a harmless one, is not a vulnerability: open a normal issue for those.

## Supported versions

Only the latest release gets fixes.
